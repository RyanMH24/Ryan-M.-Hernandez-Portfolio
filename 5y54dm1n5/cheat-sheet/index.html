Command Cheat Sheet

Quick reference for the commands, cmdlets, and tools you'll reach for most.

Navigation & Files

  • pwd

    Print the current working directory.

    pwd
  • ls -la

    List files in a directory, including hidden ones, with permissions and ownership.

    ls -la /etc
  • cd

    Change the current directory. `cd ..` moves up one level; `cd` alone goes home.

    cd /var/log

Viewing & Editing Files

  • cat

    Print a file's contents straight to the terminal.

    cat /etc/hosts
  • less

    Page through a long file one screen at a time instead of dumping it all at once.

    less /var/log/syslog
  • cp

    Copy a file or directory to a new location.

    cp notes.txt backup.txt
  • mv

    Move or rename a file — renaming is just moving it to a new name in place.

    mv old.txt new.txt
  • rm -rf

    Delete files or directories permanently — there's no recycle bin. Double-check the path first.

    rm -rf build/

Processes & Services

  • ps aux

    List every running process, for every user, with CPU and memory use.

    ps aux | grep nginx
  • kill -9

    Force-terminate a process by its process ID (PID).

    kill -9 1234
  • systemctl status

    Check whether a service is running and view its recent log lines.

    systemctl status nginx
  • systemctl restart

    Restart a system service.

    systemctl restart nginx

System Info & Resources

  • top

    Show live CPU and memory usage per process, updating in real time.

    top
  • df -h

    Show disk space usage for every mounted filesystem, in human-readable units.

    df -h
  • du -sh

    Show the total size of a directory.

    du -sh /var/log
  • free -h

    Show total, used, and free memory and swap.

    free -h

Networking

  • ping

    Test connectivity to a host by sending it ICMP echo requests.

    ping 8.8.8.8
  • ip a

    Show network interfaces and their assigned IP addresses.

    ip a
  • ss -tulpn

    List listening ports and the processes using them.

    ss -tulpn

Users & Permissions

  • chmod

    Change a file's permission bits (read/write/execute for owner, group, others).

    chmod 755 script.sh
  • chown

    Change a file's owning user and group.

    chown www-data:www-data index.html
  • sudo

    Run a single command with administrator (root) privileges.

    sudo apt update
  • whoami

    Print the currently logged-in user.

    whoami

Search & Filter

  • grep

    Filter lines of text matching a pattern — one of the most-used commands in troubleshooting.

    grep -i error /var/log/syslog
  • find

    Search a directory tree for files by name, type, or other attributes.

    find / -name "*.log"

Package Management

  • apt

    Install, update, or remove software packages on Debian/Ubuntu systems.

    sudo apt install curl

Shell Basics

  • man

    Open the manual page for a command — the first place to check when unsure of its flags.

    man ls

Common Tools & Locations

  • /etc/passwd

    The file listing local user accounts on the system.

    cat /etc/passwd
  • /etc/hosts

    Manual hostname-to-IP mappings, checked before DNS.

    cat /etc/hosts
  • /var/log

    Where most system and application log files live.

    ls /var/log
  • crontab -e

    Edit the current user's scheduled recurring jobs.

    crontab -e
