Independent Project · IT Automation

▸ W0RKFL0W5

Self-hosted n8n automation that onboards and offboards employees across Okta, Slack, and Jira from a single HR request, built like production software with feature branches, pull requests, and GitHub Actions CI.

  • Onboarding stages the Okta account for the start date, grants role-based groups from an access policy, opens a Jira setup ticket, and announces the hire in Slack.
  • Offboarding records the person's access in a Jira audit ticket before revoking sessions and deactivating the account.
  • Failures retry, then raise a Jira incident and a Slack alert; repeated requests never create duplicate accounts, tickets, or messages.
  • Docker Compose stack on Postgres; CI runs a workflow linter, 23 unit tests, and 8 end-to-end tests against mocks of the real APIs. Design choices documented in 6 architecture decision records.
